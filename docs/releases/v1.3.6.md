# ILBI v1.3.6

- Sayt, desktop login, sinxronlash, yangilanishlar, chek havolalari va qo‘llanma rasmlari yagona `https://ilbi.uz` manziliga o‘tkazildi.
- Eski vaqtinchalik serverga tarmoq ulanishi va HTTPS alias olib tashlandi. Begona server manzillari avvalgidek rad etiladi.
- Oldingi rasmiy versiyadagi shifrlangan qurilma va cloud sozlamalari yangi manzilga mahalliy tarzda ko‘chiriladi. Baza, foydalanuvchilar, sotuvlar, navbat, qoralamalar va shifrlash kalitlari saqlanadi.
- Email xabarlari `ILBI <noreply@ilbi.uz>`dan yuboriladi. Yashirin konfiguratsiya fayllari Nginx orqali ochilishi bloklandi.

Eski versiyadan birinchi o‘tishda [yuklab olish sahifasidan](https://ilbi.uz/download) yangi paketni oling, ochiq ishlarni saqlang va ILBI’ni odatdagi usulda yoping. Windows’da yangi o‘rnatuvchini ishga tushiring; Linux’da arxivni ochib, `ILBI/` ichida oddiy foydalanuvchi sifatida `bash install.sh` bajaring. Mahalliy ma’lumotlar papkasi va `device.vault` faylini o‘chirmang.
